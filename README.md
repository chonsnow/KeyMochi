# KeyMochi (MF34 Karabiner-Elements GUI Mapper)

Magicforce MF34 전용 키매핑 GUI 보조 도구 (Karabiner-Elements 연동)

## Features
- **34-Key Precision Visualizer**: Magicforce MF34 34키 레이아웃 실시간 시각화
- **Hardware Mode Switching**: Wired (노란색) / Wireless (파란색) 모드 분리 및 3개 독립 레이아웃 슬롯
- **Karabiner-Elements Auto Export**: Complex Modifications JSON 룰 원클릭 생성 및 복사
- **File Management**: [.txt], [.json] 키맵 프로파일 가져오기 / 내보내기 지원
- **Bilingual Support**: 한국어 / English 실시간 언어 전환

## Installation
최신 배포 버전은 [Releases](https://github.com/chonsnow/KeyMochi/releases)에서 `.dmg` 파일을 다운로드하여 설치할 수 있습니다.
